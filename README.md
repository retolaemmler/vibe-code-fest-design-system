# Vibe Design System

A design system library built with React, Tailwind CSS v4, and TanStack Start.
It uses a semantic token system for both light and dark modes.

## Features

- **Tailwind v4**: CSS-first design tokens and utilities.
- **Semantic Tokens**: HSL-based color system, unified radius, and elevation steps.
- **Components**: A complete set of UI components (Buttons, Cards, Nav, etc.) exported from `src/index.ts`.
- **Showcase**: A built-in preview app under `src/routes`.

## Stack

- TanStack Start + TanStack Router (file-based routing under `src/routes/`)
- React 19 + TypeScript
- Tailwind CSS v4, CVA, Radix primitives, Lucide icons

## Develop

```sh
bun install
bun run dev
```
